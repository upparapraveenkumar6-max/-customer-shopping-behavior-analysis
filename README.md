# 🛍️ Customer Shopping Behavior Analysis — SQL | Python | Power BI

An end-to-end data analytics project that explores customer shopping behavior using **Python** (data cleaning & EDA), **SQL** (business-question querying), and **Power BI** (interactive dashboarding) — built to answer real retail business questions and present the findings clearly to stakeholders.

---

## 📌 Project Overview

Retail businesses generate huge volumes of transaction data, but raw data alone doesn't drive decisions — insights do. This project simulates a full analyst workflow on a customer shopping dataset (**3,900 transactions**, 18 attributes) to uncover:

- Revenue patterns across gender, age, and product category
- The real impact of discounts, promo codes, and subscriptions on spend
- Product-level performance (ratings, discount sensitivity, top sellers)
- Customer segmentation (New / Returning / Loyal) based on purchase history
- Shipping method and payment behavior trends

**Workflow:**

1. **Python** → Import, clean, and explore the raw dataset; load it into a SQL database
2. **SQL** → Answer 10 targeted business questions using aggregations, window functions, and CTEs
3. **Power BI** → Build an interactive dashboard visualizing key metrics for stakeholders
4. **Reporting** → Summarize findings and recommendations in a business report and presentation deck

## 📊 Dataset

**3,900 customer transactions** with the following fields:

`Customer ID`, `Age`, `Gender`, `Item Purchased`, `Category`, `Purchase Amount (USD)`, `Location`, `Size`, `Color`, `Season`, `Review Rating`, `Subscription Status`, `Shipping Type`, `Discount Applied`, `Promo Code Used`, `Previous Purchases`, `Payment Method`, `Frequency of Purchases`

---

## ❓ Business Questions Answered (SQL)

1. Total revenue generated by male vs. female customers
2. Customers who used a discount but still spent above the average purchase amount
3. Top 5 products by average review rating
4. Average purchase amount: Standard vs. Express shipping
5. Do subscribers spend more? Comparing avg. spend & total revenue by subscription status
6. Top 5 products by discount usage rate
7. Customer segmentation — New / Returning / Loyal — based on purchase history
8. Top 3 most purchased products within each category
9. Are repeat buyers (5+ previous purchases) more likely to subscribe?
10. Revenue contribution by age group
